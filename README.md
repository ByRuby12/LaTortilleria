# La Tortillería

## 📋 Sobre este proyecto

**La Tortillería** es una web de carta digital diseñada para mostrar de forma clara y atractiva la oferta del establecimiento desde cualquier dispositivo, especialmente desde móviles.

La web incluye una navegación por categorías, fichas de productos con nombre, descripción, precio e información de alérgenos, imágenes de los productos, sección de contacto y enlaces a servicios de entrega. También incorpora cambio de idioma, modo claro/oscuro y una interfaz responsive adaptada a diferentes tamaños de pantalla.

El proyecto utiliza una estructura web basada en **HTML, CSS y JavaScript**, con integración de Firebase para la gestión de determinados contenidos y datos de la web.
